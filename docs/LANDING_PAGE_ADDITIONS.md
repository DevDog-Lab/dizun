## 1. 追加された機能の概要

ZIP に加えて、**tar 系・7z・RAR・LZH** の圧縮・解凍に対応した。エンジンは2層構成:

- **ZIP は独自エンジン（DizunCore）を維持** — 日本語ファイル名の CP932 自動検出・暗号化（AES-256/ZipCrypto）・二重ZIP化という DIZUN の中核価値を守る
- **ZIP 以外は監査済み固定版 libarchive を同梱**（SHA 固定・依存完全固定ビルド・上流テスト 1152/1152 合格）。LZMA 圧縮のため liblzma（XZ Utils v5.8.4、0BSD）も同梱

## 2. 対応形式マトリクス（LPの表にそのまま使える形）

| 形式 | 作成 | 解凍 | プレビュー | 備考 |
| --- | --- | --- | --- | --- |
| ZIP | ✓ | ✓ | ✓ | 暗号化・文字コード切替は ZIP のみ |
| TAR | ✓ | ✓ | ✓ | 圧縮なしでまとめるだけ |
| TAR.GZ / TGZ | ✓ | ✓ | ✓ | 追加圧縮形式の既定候補 |
| TAR.BZ2 / TAR.XZ | ✓ | ✓ | ✓ | メニューの詳細候補 |
| 7z | ✓ | ✓ | ✓ | LZMA2。受け取る側に対応アプリが必要な場合あり |
| RAR（RAR4/RAR5） | — | ✓ | ✓ | **受信救済専用**（作成しない） |
| LZH / LHA | — | ✓ | ✓ | 日本語レガシー資産の救済。CP932 日本語ファイル名に対応 |
| 単体 .gz / .bz2 / .xz | — | ✓ | ✓（1項目） | 中身が tar なら自動で tar として扱う |

対応しないもの（正直に表示）: 暗号化 7z/RAR、分割アーカイブ、SFX。検出して説明を表示するが「対応」とは呼ばない。

## 3. ユーザー体験の変化（ストーリーにできる要素）

1. **形式を選べる圧縮**: ドロップレット窓に「形式」ポップアップ（ZIP が既定。TAR.GZ、7z など）。**選択はその場限りで、次回起動時は常に ZIP に戻る** — うっかり相手が開けない形式で送る事故を防う設計
2. **ドラッグ&ドロップするだけで自動判別**: 拡張子でなく**中身（マジックバイト）で形式を判定**。`.zip` と名乗る RAR でも正しく扱い、プレビューで「拡張子は ZIP ですが、内容は RAR です」と通知
3. **解凍前プレビューが全形式に**: 形式バッジ・件数・サイズ・日本語ファイル名の一覧を表示してから解凍
4. **同名フォルダがあっても安心**: 解凍先に同じ名前のフォルダがあると、新しい中身は「名前 2」として分離。**既存のファイルは一切上書きしない**（ZIP と同じ約束を全形式に適用）
5. **Finder 統合の拡大**: tar/7z/RAR/LZH をダブルクリックで開く・右クリック「DIZUNで解凍」の対象に
6. **LZH の日本語**: CP932 の日本語ファイル名（例: 漢字.txt）を正しく復号

## 4. LP 向けコピー案

### 機能カード（ja / en）

- **「もっと多くの形式を、そのまま DIZUN で。」/ "More formats, one DIZUN."**
  - TAR.GZ、7z、RAR、LZH まで。ドラッグすれば形式を自動で見分け、プレビューして、安全に展開します。
  - TAR.GZ, 7z, RAR and LZH too. Drop anything — DIZUN detects the format, previews it, and extracts it safely.
- **「受け取った RAR も、LZH も。」/ "That RAR you received. That old LZH archive."**
  - 開けない書庫のために別のアプリを探さなくてよくなります。古い日本語の LZH のファイル名も文字化けさせません。
  - No more hunting for another app. Even legacy Japanese LZH names decode without mojibake.
- **「送る形式は、その場で選ぶ。」/ "Pick the format per drop."**
  - 既定は ZIP。必要なときだけ TAR.GZ や 7z に切り替えられ、次回起動時は自動で ZIP に戻ります。
  - ZIP by default. Switch to TAR.GZ or 7z when needed — it always returns to ZIP.

### 動作の説明（プレビュー表示例）

- 形式バッジ: `ZIP` / `TAR · GZIP` / `7z` / `RAR5` / `LZH`
- 拡張子不一致: 「拡張子は ZIP ですが、内容は RAR です。/ The extension is ZIP; the contents are RAR.」

### 技術の信頼性セクションに追記できる文

- ZIP 以外のエンジンには、広く使われるオープンソース libarchive を**バージョンを固定して同梱**しています（依存ライブラリを含めビルド条件を完全に固定・上流テスト 1152 項目を全合格させてから）。ネットワーク通信は従来どおり一切ありません。
- 書庫の展開はすべて DIZUN 自身の安全層を通ります: 危険なパスの拒絶、上書きしない保証、展開サイズの上限、リンクの無効化。

### FAQ 追加候補

- **Q. RAR ファイルは作れますか?** — いいえ、RAR は受け取ったファイルを開くための対応です（RAR の作成は独自形式のため行いません）。
- **Q. 暗号化された 7z や RAR は開けますか?** — 現在は対応していません。開こうとすると、暗号化されていることが通知されます。
- **Q. 分割された書庫（.part1.rar など）は?** — 現在は対応していません。統合された状態でお使いください。

## 5. スクリーンショット候補

1. ドロップレット窓の ZIP タブ（「形式」ポップアップが TAR.GZ を表示し、文字コード・暗号化が無効化された状態）
2. TAR.GZ を開いた解凍前プレビュー（TAR.GZ バッジ＋日本語ファイル名の一覧）
3. 同名フォルダがある状態での解凍結果（`src` と `src 2` が並ぶ Finder 表示）
