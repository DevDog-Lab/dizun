# DIZUN（ディズン）

**macOS向け 圧縮・解凍・画像最適化アプリ — 開発中・未配布**

DIZUN は、日本語ファイル名の文字化けと OS 間のファイル交換を静かに、確実に扱うための macOS ネイティブアプリです。テレメトリも広告もネットワーク通信もありません。

> 「固める。開く。迷わない。」はタグライン候補であり、正式決定ではありません。

## 名前の仕掛け

小文字の **`unzip`** を180度回転させると **`dizun`** と読める——この視覚的な反転を名前の核にしています。回転が「逆の操作」を象徴するように、解凍（unzip）と圧縮（zip）の双方向をひとつの名前に込めています。

## 実装済みの機能

すべて下記の検証状況のとおり動作することを確認したものだけを記載します。

### ZIP 圧縮・解凍（独自エンジン）

- 圧縮: Store / Deflate、ZIP64、16MB超のストリーミング書き込み、既存ファイルの上書き防止付き排他作成
- 解凍: UTF-8フラグ優先・CP932自動検出・手動指定、Info-ZIP Unicode Path extra 対応、CRC・サイズ検証
- 文字コード: 圧縮時に UTF-8（NFC正規化）または CP932（Windows互換）を選択。CP932で表現できない名前は明確にエラー
- `__MACOSX/` 等の macOS ジャンクを圧縮・解凍の両面でスキップ
- 暗号化 ZIP: **AES-256（WinZip拡張）** と **ZipCrypto** に対応。暗号化圧縮ではエントリ名・構成が平文で見えないよう自動的に二重ZIP化し、DIZUNでは自動アンラップ
- 外部ツール交叉検証: 7-Zip 26.00・Info-ZIP unzip・ditto・python zipfile と双方向で内容一致を確認

### 画像最適化

- PNG: テキスト/EXIF系チャンク削除、IDAT再圧縮（スキャンラインはバイト完全一致）
- JPEG: EXIF/XMP/IPTC/COM削除、スキャンデータは逐語コピー（画素ビット完全一致）。orientation は事前に画素へ焼き込み
- 長辺上限リサイズ、JPEG目標サイズ（KB以下）探索、元画像のゴミ箱退避（設定可）
- 安全策: 必ず小さくなる場合のみ置換、一時ファイル→検証→アトミック置換

### Mac らしい操作

- ドロップレット窓: ファイルをドロップするだけ。ZIP は解凍、画像は最適化、ほかは圧縮
- Finder統合: `.zip` ダブルクリック解凍、右クリックサービス（DIZUNで圧縮 / 圧縮（暗号化）/ 解凍）、Dockアイコンへのドロップ（未起動ピン留めも対応）
- 解凍前プレビュー: 内容一覧・文字コード手動切替（自動判定結果つき）・暗号化/未対応方式の警告
- UI言語: 日本語 / English 切替（即時反映）
- CLI: `dizun pack / unpack / list / selftest`

### 安全性の設計

- Zip Slip 防御（絶対パス・`..`・ドライブ文字・バックスラッシュ）、symlink スキップ
- **既存ファイルは絶対に上書きしない**（衝突時は自動ユニーク名）
- zip bomb 対策: 膨張比上限・総量キャップ・件数リミット・事前容量バジェット
- キャンセル時は自己作成分をクリーンアップ、quarantine 属性は継承
- 通常解凍ではファイル本文のバイト列を変更しません（テキスト変換は別機能としてのみ構想中）

## 検証状況と互換性

| 項目 | 状況 |
| --- | --- |
| 独自テスト | XCTest 25シナリオ全合格（暗号化・文字化け・防御系を含む） |
| Mac 上での相互運用 | 7-Zip / Info-ZIP unzip / ditto / python zipfile と双方向で内容一致を確認済み |
| **Windows 実機での相互試験** | **未検証**（ゲートD）。Windows 実機での開封・作成を保証する記述は、実機検証が完了するまで行いません |
| 配布 | 未実施（コード署名・notarization は未実施。現在はソースからビルドして利用） |

CP932 モードは「日本語環境の Windows 受信者」向けの前提です。7-Zip on Mac が CP932 ZIP の展開に失敗するのは Mac 側ロケールの制約であり、日本語ロケールの Windows では CP932 がシステム既定のため動作する系統です（実機検証は上表のとおり未実施）。

## 動作環境・ビルド

- macOS 14 以降、Apple silicon
- ビルド: Xcode 27.2 ツールチェーンで `./scripts/build-app.sh`（SwiftPM リリースビルド → `/Applications/DIZUN.app` へインストール）
- テスト: `swift test`
