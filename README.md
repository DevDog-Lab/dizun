# DIZUN（ディズン）

**macOS向け圧縮・解凍アプリ — 開発中 / 未リリース**

> 「固める。開く。迷わない。」はタグライン候補であり、正式決定ではありません。

**DIZUN** は `unzip` の文字列全体を180度回転させると `dizun` という字形になる発想から生まれました。回転が象徴する「逆方向」と、解凍（unzip）／圧縮（zip）の双方向性を一つの名前に込めています。ロゴとしての可読性・字形は今後検証します。

## 開発の目標（未実装を含む）

- Windows/macOS間のZIP交換で、日本語ファイル名が文字化けする問題を軽減
- Finderのダブルクリック解凍、右クリックからの圧縮
- UTF-8/CP932の扱い、解凍前プレビューと曖昧な場合の手動選択
- 通常解凍はファイル本文のバイト列を変更しない（テキスト変換は別機能）
- 広告、テレメトリ、解析、クラウド送信なしのローカルアプリ
- 危険なアーカイブへの防御、上書き事故防止、Mac/Windows実機相互テスト

**現時点で対応形式・動作保証・配布パッケージは確定していません。** 機能の実装状況・互換性は検証結果に合わせて更新します。
